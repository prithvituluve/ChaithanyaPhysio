# Dr Chaithanya H. Devadiga — Home Physiotherapy Website

Latest redesign: teal, navy and white theme, updated portrait, illustrated treatment sections, and home-visit booking emphasis.

## Preview
Extract this ZIP and open index.html in your browser. Keep the files together.

## Publish on GitHub Pages
Upload all files from inside this ZIP into the root of your website repository, replacing the previous website files. Keep index.html at the repository root. Commit the changes; your configured Pages deployment will publish them.

This is a static website. No build command, dependencies, API keys, or server are needed.

## Files
- index.html: website content
- style.css: desktop and mobile layouts
- script.js: WhatsApp enquiry form
- chaithanya-new.jpg: supplied portrait
- home-physiotherapy.png: AI-generated illustrative treatment scenes used as a CSS image grid
